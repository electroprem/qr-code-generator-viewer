# QR Code Generator & Viewer

A fast, easy-to-use QR code generator and viewer web app that supports:

- Single or batch QR code generation (batch items separated by semicolon `;`)
- Persistent history of generated QR codes saved locally in the browser
- View all past generated QR codes in a responsive grid with encoded text
- Download each QR code as PNG with one click
- Clear saved QR history anytime
- Works completely offline after initial load (only dependency is a CDN JS library)

## Features

- **Batch Generation:** Generate multiple QR codes at once by entering semicolon-separated items
- **History Persistence:** Your generated QR codes are saved in localStorage and restored on page reload
- **Responsive UI:** View QR codes and their encoded text in a clean, mobile-friendly grid layout
- **Download Support:** Download any QR code image directly
- **Clear History:** Easily clear saved QR codes to free up space or reset
- **No Backend Needed:** Fully client-side, just open the HTML file or host on GitHub Pages

## Usage

1. Enter any text or multiple texts (separated by semicolons `;`) to generate single or batch QR codes.
2. Click **Generate (auto-detect)** or **Batch Generate**.
3. Navigate to the **View** tab to see your QR codes and encoded texts.
4. Use the **Download** button on each QR code to save it as a PNG.
5. Use the **Clear history** button to remove all saved QR codes.

## Why Use This?

Quickly create QR codes for URLs, WiFi credentials, contacts, inventory numbers, and anything else — all from your browser without installing software or relying on internet access after the first load.
